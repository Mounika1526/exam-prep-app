## Routing

Uses TanStack Router with the Vite plugin for file-based routing. Routes auto-generate `src/routeTree.gen.ts`.

### Naming Conventions
| File Pattern | URL Pattern |
|-------------|------------|
| `__root.tsx` | Root layout (wraps everything) |
| `index.tsx` | `/` |
| `_auth.tsx` | Pathless layout (auth pages) |
| `_auth.login.tsx` | `/login` |
| `_dashboard.tsx` | Pathless layout (requires auth) |
| `_dashboard.index.tsx` | `/dashboard` |
| `_dashboard.exams.$examId.tsx` | `/exams/:examId` |

### Protected Routes

All `_dashboard.*` routes redirect to `/login` if no JWT token in Zustand store.
Auth routes redirect to `/dashboard` if already logged in.

## State Management

### Server State — TanStack Query
```typescript
// Example: fetching exam data
const { data, isLoading } = useQuery({
  queryKey: ['exam', examId],
  queryFn: () => api.get(`/exams/${examId}/subjects`).then(r => r.data),
})
```

### Client State — Zustand
```typescript
// Auth store (persisted to localStorage)
const { user, token, setAuth, logout } = useAuthStore()
```

## Key Patterns

### API calls with error handling
```typescript
const mutation = useMutation({
  mutationFn: (data) => api.post('/endpoint', data).then(r => r.data),
  onSuccess: (data) => { /* handle success */ },
  onError: (err: any) => {
    toast({ title: 'Error', description: err.response?.data?.error, variant: 'destructive' })
  },
})
```

### Protected route navigation
```typescript
// In component
const navigate = useNavigate()
navigate({ to: '/dashboard' })

// In route beforeLoad
beforeLoad: () => {
  if (!token) throw redirect({ to: '/login' })
}
```

### File naming
- `PascalCase.tsx` for React components
- `camelCase.ts` for utilities, hooks, stores
- `kebab-case.tsx` for route files (TanStack Router convention)
